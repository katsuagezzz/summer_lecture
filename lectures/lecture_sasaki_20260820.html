今日の問い：円安・金利・物価は、それぞれ別のニュースではなく1本の輪である。どの向きに、どうつながっているか？

ゴールは暗記ではない。「円が安くなると、なぜ物価が上がって、なぜ日銀が金利を上げるのか」を、矢印3本で口で言えること。細かい例外は今日は全部捨ててよい。

9:03–9:10

三角形を一周する

為替・物価・金利。ニュースでは別々の記事として出てくるが、実際にはこの3つは順番に押し合っている。 まず輪を1周させて、そのあと「いま、輪のどこが詰まっているか」を見る。

矢印は3本しかない。順に日本語で言ってみる。

①円が安くなる→輸入するモノが円では高くなる→物価が上がる 石油・小麦・半導体・服。日本は使うものの多くを外から買っている。ドルでの値段が同じでも、円が安ければ日本での値段は上がる ── 演習1でこれを電卓で確かめる。
②物価が上がる→中央銀行（日銀）が金利を上げる 金利は「お金を借りる値段」。上げると借りにくくなり、世の中に出回るお金が減り、物価の上がり方が鈍る。冷房のスイッチだと思っておく。
③金利が上がる→その国の通貨が買われる→通貨高（円高） 金利が高い国にお金を置いた方が多く儲かるから、世界のお金がそっちへ動く。動くにはその国の通貨を買う必要がある。だから「金利が高い通貨は買われる」。

この③が効けば円高に戻り、輸入物価が下がり、インフレが収まる ── 教科書ではここで輪が止まる。ところが実際には止まっていない。理由は次のセクションの数字にある。

ズレ① ── 川上の +29.1% は、川下で +1.6% になっている

物価の統計は1つではない。誰が誰に売るときの値段かで3つに分かれていて、川上から川下へ順に並ぶ。 そして下るたびに、上がり方がどんどん小さくなる。

仕入れ値が +29.1% 上がっているのに、店頭価格は +1.6% しか上がっていない。差の 27.5ポイント は、誰が飲んだのか？

ここが今日いちばん大事なところ。ヒントは前回のZOZOでやった原価率にある ── 仕入れが上がったのに売値を上げられなければ、削られるのは会社の利益だ。議論Q1で正面からやる。

ズレ② ── 日銀は利上げした。それでも円安は止まらない

日銀は2024年3月にマイナス金利をやめてから、2年あまりかけて0%台から1.00%まで金利を上げてきた。 「金利を上げれば円高になる」なら、円は高くなっているはずだ。ところが8月のドル円は158〜160円台にいる。

理由は「日本の金利が上がったかどうか」ではない。相手（アメリカ）との差がいくつ開いているかだ。 お金は「上がった国」ではなく「いま置いておくと得な国」へ動く。

日米の政策金利差=3.625%−1.00%=約 2.6 ポイント 1年前より差は縮んだ。それでも「ドルで持っている方が年2.6%ぶん得」という状態は続いている。日銀が1回（0.25%）利上げしても、差は 約2.4ポイント に縮むだけ ── 方向ではなく水準で見るのが今日の型。
9:18–9:25

計算演習 ── 電卓を出して

「円安だと物価が上がる」は、聞けば当たり前に聞こえる。自分で割ると、当たり前ではなくなる。3問。

演習 1

原油の値段が1バレル80ドルだとする。1ドル＝150円のとき、日本円ではいくらか？　1ドル＝160円になったら？　円建てでは何%の値上がりか？

ヒント: 原油のドル建て価格は1ドルも動いていない。動いたのは為替だけ

答えを開く

80ドル × 150円 = 12,000円　／　80ドル × 160円 = 12,800円　／　800 ÷ 12,000 ≒ +6.7%

産油国は値上げしていない。世界の需給も変わっていない。円が10円安くなっただけで、日本のガソリンの原料は6.7%値上がりする。 これが「円安 → 物価」の矢印の正体で、日本が石油・小麦・肉・半導体を外から買っている限り必ず起きる。 ここで一度、自分ごとに引き寄せておく ── 君がバイト代で入れるガソリンも、コンビニのパンも、同じ経路で上がっている。

演習 2

2026年7月の輸入物価は、契約通貨ベースで +17.7%、円ベースで +29.1%だった。 このうち「円安のせい」はどれくらいか？

ヒント: 契約通貨ベース＝ドルなど「売り手が請求した通貨のままの値段」。円ベース＝それを円に直した値段。差が為替の効果

答えを開く

ざっくり（引き算）: 29.1 − 17.7 = 11.4ポイント　／　正確に（割り算）: 1.291 ÷ 1.177 − 1 ≒ +9.7%

モノそのものの値上がりが +17.7%。そこに円安が約10%ぶん上乗せして、日本に着いたときには +29.1% になっている。 日本が輸入で払っている追加の値上がりのうち、3〜4割は「為替のぶん」だということ。

なお、率どうしを引き算すると「ポイント」、割り算すると「%」になる。 ニュースは引き算で書くことが多いが、正確には割り算だ ── 前回の「分母は何か」と同じ話で、 率を足し引きした瞬間に、それは近似になる。大枠をつかむには引き算でよい。使い分けられることが大事。

演習 3

金利が1.00%の国と3.625%の国。ただし物価は前者が +1.6%、後者が +3.4% 上がっている。 100万円を1年置いたとき、買えるモノの量が増えるのはどちらか？

ヒント: 実質金利 ＝ 名目金利 − インフレ率。「増えたお金」から「値上がりぶん」を引くと、本当に増えた量が出る

答えを開く

日本: 1.00 − 1.6 = −0.6%　／　米国: 3.625 − 3.4 = +0.2%

日本に置くと、利息はつくのに買えるモノは0.6%減る。アメリカに置くとかろうじて0.2%増える。 世界のお金がドルへ向かう理由はここにある ── そしてドルを買うには円を売るから、円安になる。 三角形の③の矢印は「日本の金利が上がったか」ではなく、「相手より得か」で決まる。

この 実質金利＝名目金利 − インフレ率 は、今日いちばん持ち帰ってほしい式。 銀行の金利が1%でも物価が2%上がっていれば、預金は減っている。君の貯金にそのまま効く話だ。

Q1

今日の「三角形」の矢印の向きとして正しいものはどれか？

  1. 円安 → 物価が下がる → 金利が下がる
  2. 円安 → 物価が上がる → 金利が上がる →（本来は）円高に戻る
  3. 金利が上がる → 物価が上がる → 円安になる
  4. 物価が上がる → 円安になる → 金利が下がる
答えを見る

正解: B

円が安くなると輸入品が円建てで高くなって物価が上がり、中央銀行は熱を冷ますために金利を上げる。金利が上がればその通貨が買われて通貨高に戻る ── これで輪が閉じる。いまの日本は最後の1本が弱く、輪が閉じきっていない。

Q2

1バレル80ドルの原油。為替が1ドル＝150円から160円になったとき、円建て価格の値上がり率に最も近いのはどれか？

ヒント: 演習1と同じ計算。ドル建て価格は動いていない

  1. 約 0%（ドル建てが同じなので変わらない）
  2. 約 6.7%
  3. 約 10%
  4. 約 16%
答えを見る

12,000円 → 12,800円　800 ÷ 12,000 ≒ +6.7% → 正解: B

産油国は1ドルも値上げしていないのに、日本での値段は6.7%上がる。「円安 → 物価」の矢印は、この計算そのもの。

Q3

2026年7月の輸入物価は契約通貨ベース +17.7%、円ベース +29.1% だった。この2つの差が意味するものはどれか？

  1. 統計の集計ミスの範囲
  2. 輸入した数量が増えたぶん
  3. 円安によって上乗せされた値上がりぶん
  4. 関税が引き上げられたぶん
答えを見る

正解: C（引き算で11.4ポイント、割り算で約+9.7%）

契約通貨ベースは「請求された通貨のままの値段」、円ベースは「円に直した値段」。同じモノの同じ値段を、通貨だけ変えて見ているので、差はまるごと為替の効果になる。

Q4

「君がコンビニのレジで払う値段」に最も近い統計はどれか？

  1. 輸入物価指数
  2. 国内企業物価指数（PPI）
  3. 消費者物価指数（CPI）
  4. 10年国債利回り
答えを見る

正解: C

川上（輸入物価 +29.1%）→ 川中（企業物価 +7.2%）→ 川下（消費者物価 +1.6%）。下るほど上がり方が小さくなる。日銀が2%目標で見ているのはいちばん下のCPI（コア）。

Q5

政策金利1.00%、消費者物価の上昇率+1.6%の国。100万円を1年預けたとき、買えるモノの量はどうなるか？

ヒント: 実質金利 ＝ 名目金利 − インフレ率

  1. 1.0%ぶん増える
  2. 2.6%ぶん増える
  3. 変わらない
  4. 0.6%ぶん減る
答えを見る

1.00 − 1.6 = −0.6% → 正解: D

利息はついているのに、値段の方がそれ以上に上がるので、買える量は減る。「金利がつくから預金は安全」が、いつも正しいとは限らない ── というのが実質金利の教え。

Q6

日銀は2024年3月から2026年6月にかけて政策金利を1.00%まで引き上げた。それでも円安が続いている理由の説明として、本文に沿うものはどれか？

  1. 日本の金利が下がり続けているから
  2. 米国の金利が3.50〜3.75%と高く、差が約2.6ポイント開いたままだから
  3. 為替は金利とはまったく関係がないから
  4. 日本の輸入物価が下がっているから

Q7

コアCPI（コア消費者物価指数）の「コア」とは、何を除いた指数か？

  1. 生鮮食品
  2. 住居費
  3. 輸入品すべて
  4. サービス
答えを見る

正解: A（生鮮食品を除く総合）

野菜や魚は天候で乱高下するので、物価の基調を見るには邪魔になる。そこを除いたのがコア。さらにエネルギーも除くと「コアコア」。日銀の2%目標が見ているのはコア。
